# Консольный калькулятор: многофайловый проект и модульные тесты

Предмет: Поддержка и тестирование программных модулей.  
Практическая работа: многофайловый C++-проект и модульное тестирование.  
Выполнил: Куранов Артем, РПО-3.

## 1. Назначение и основание работы

Программа получает два целых числа и выводит сразу четыре результата: сумму, разность, произведение и частное. Деление может давать дробный результат. При нулевом делителе выводится сообщение «На ноль делить нельзя», а остальные три результата вычисляются.

За основу взяты описание варианта А «Консольный калькулятор» и план тестирования из предыдущей работы. Его текст находится в [docs/previous-test-plan.txt](docs/previous-test-plan.txt). В предоставленном архиве был текстовый документ в формате HTML; исходного `.cpp` или проекта Visual Studio не было. Поэтому этот проект подготовлен по описанному поведению. Совпадение реализации и всех особенностей старой программы не проверялось.

Для негативных сценариев предыдущего плана добавлены проверка ввода и повторный запрос при ошибке. Для результатов целых операций выбран `long long`, чтобы два допустимых 32-битных числа не приводили к арифметическому переполнению.

История вычислений упоминается в предыдущем плане как отсутствующая возможность для дальнейшей доработки. В этой работе она не реализована: в текущем задании она не требуется, а её формат и сценарии не определены. Программа выполняет один расчёт для одной пары чисел за запуск.

## 2. Требования

- Windows и Visual Studio 2022 или Visual Studio 2026.
- Рабочая нагрузка «Разработка классических приложений на C++» / Desktop development with C++, MSVC и Windows SDK.
- Microsoft Unit Testing Framework for C++, который входит в указанную рабочую нагрузку.

Решение настроено для `Debug | x64` и `Release | x64`. Язык - C++14, кодировка исходников - UTF-8, уровень предупреждений - `/W4`. Используется стандартный набор инструментов установленной Visual Studio, без жёсткой привязки к v143 или v145. Предварительно скомпилированные заголовки отключены.

Сторонние библиотеки и NuGet-пакеты для этого решения не нужны.

## 4. Как открыть и собрать

1. Полностью распаковать архив в папку, например `C:\Projects\Calculator_Modules_Kuranov`.
2. Открыть `Calculator.sln` в Visual Studio.
3. В верхней панели выбрать Debug и x64.
4. Выполнить «Сборка → Пересобрать решение».
5. В обозревателе решений щёлкнуть правой кнопкой по проекту App и выбрать «Назначить запускаемым проектом».
6. Нажать Ctrl+F5 для запуска без отладки.

После успешной сборки приложение находится в `x64/Debug/App.exe`, тестовая библиотека - в `x64/Debug/App.Tests.dll`.

Если не найден `CppUnitTest.h`, открыть Visual Studio Installer, изменить установленную Visual Studio и проверить наличие рабочей нагрузки C++ и компонентов тестирования. Если отсутствует Windows SDK или набор инструментов, установить компонент либо выбрать установленный набор в свойствах обоих проектов. Отдельно скачивать файл `CppUnitTest.h` не требуется.

## 5. Использование программы

Каждое число вводится **с новой строки**. Разрешены значения от `-2147483648` до `2147483647`, необязательный знак и пробелы по краям. Буквы, дробная запись, пустая строка, несколько чисел в одной строке и числа вне диапазона отклоняются. После ошибки программа повторяет запрос того же числа.

Пример для `5` и `2`:
Консольный калькулятор
Введите два целых числа (каждое с новой строки).
Введите первое целое число: 5
Введите второе целое число: 2
Сумма: 7
Разность: 3
Произведение: 10
Частное: 2.5

Для `8` и `0`:
Сумма: 8
Разность: 8
Произведение: 0
На ноль делить нельзя

Дробный результат выводится с точкой и до 15 значащих цифр. Конец входного потока завершает программу с сообщением «Ввод завершён.» и кодом `1`; успешно полученная пара обрабатывается с кодом завершения `0`.

## 6. Как запустить Microsoft Unit Tests

1. Собрать решение в Debug | x64.
2. Открыть «Тест → Обозреватель тестов».
3. После обнаружения тестов нажать «Выполнить все».
4. В решении подготовлено 35 методов тестирования: 11 вычислений, 16 ввода и 8 вывода.
5. После изменений проверить фактический результат повторного запуска и обновить [docs/test-results.md](docs/test-results.md).

Каждый тест готовит собственные данные. Для ввода и вывода используются независимые строковые потоки. Общего изменяемого состояния, общих файлов и зависимости от порядка тестов нет. Сценарии включают позитивные, граничные и негативные проверки. Вызов `Divide` с нулевым делителем проверяется через `Assert::ExpectException<std::invalid_argument>`.

Текущий статус на 22.11.2026: на компьютере автора в Microsoft Test Explorer обнаружены и успешно выполнены все 35 тестов. Неудачных тестов - 0; в панели обозревателя тестов указаны 0 ошибок и 0 предупреждений. Подтверждение - [скриншот Test Explorer](docs/screenshots/test-explorer.png). Автор также сообщил, что решение собрано без ошибок. Подробности и отдельный статус ручной проверки консоли Windows - в [отчёте](docs/test-results.md).
